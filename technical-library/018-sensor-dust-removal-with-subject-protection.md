# 실제 피사체를 보호하는 센서 먼지 탐지·제거·검수

먼지 후보를 시각화해 자동 제거한 뒤 실제 피사체 오검출과 누락을 교정하고, 촬영 세트에서는 먼지 제거 설정만 복사해 각 이미지 결과를 독립 검수한다.

## 적용 조건

- 같은 촬영 세트의 여러 사진에 센서 먼지 자국이 반복되는 경우에 적용한다.
- 하늘의 먼 새나 작은 실제 피사체가 먼지로 오인될 수 있어 자동 제거 후 검수가 필요한 이미지에 적용한다.

## 기술 절차

1. 먼지 후보가 잘 보이도록 시각화 상태와 임계값을 이미지에 맞춘다.
2. 자동 먼지 제거를 적용하고 확대해 누락과 실제 피사체 오검출을 확인한다.
3. 놓친 먼지는 국소 제거로 보완하고 잘못 제거된 실제 피사체는 복원한다.
4. 촬영 세트에서는 다른 보정과 섞지 않고 먼지 제거 항목만 복사해 각 이미지에서 다시 분석되도록 한다.
5. 일괄 처리 뒤 다양한 구도와 배경의 사진을 검사해 결과를 확정한다.

## 파라미터 가이드

- 원문은 Threshold와 브러시 크기 수치를 제시하지 않으므로 이미지별 시인성과 결함 크기에 맞춘다.
- 복사 설정은 다른 편집을 제외하고 Dust 항목만 선택하는 원칙을 따른다.
- Generate AI 사용 시 센서 먼지로 확실한 작은 결함만 제거하고 별·새·피부 점·텍스처는 보호 대상으로 명시한다.

## 판단 근거

- 센서 먼지는 촬영 세트 전체에 반복되어 결과 품질과 작업 시간을 크게 좌우하며, 실제 피사체 오검출을 막는 검수 가치가 높다.
- Adobe 공식 근거가 단일 이미지 탐지·제거, 오검출 복구, Dust-only 일괄 적용 순서를 직접 제공한다.
- Generate AI의 정밀 물체 제거로 단일 이미지 원리는 실행할 수 있지만 현재 런타임은 Lightroom식 배치 재계산을 직접 지원하지 않고 독립 근거도 하나뿐이므로 candidate가 적절하다.

## 주의사항

- 먼 새, 별, 피부 점과 실제 작은 물체를 센서 먼지로 오인해 제거하지 않는다.
- 자동 결과를 검사하지 않은 채 촬영 세트 전체에 확정 적용하지 않는다.
- 누락을 넓은 생성형 수정으로 덮어 주변의 구름·하늘 그라데이션·표면 질감을 바꾸지 않는다.
- 영역 AI 마스크 이후 먼지 제거로 렌더링 순서가 달라질 수 있는 워크플로에서는 처리 순서를 확인한다.

## 충돌 및 예외

- 실제 장면의 작은 피사체가 먼지와 구분되지 않으면 자동 일괄 제거보다 개별 확인을 우선한다.
- 현재 Generate AI는 Lightroom의 Dust-only 복사와 각 이미지 재계산을 대체하지 않으므로 배치 기능으로 과장하지 않는다.
