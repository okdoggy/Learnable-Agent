# 배경 교체 후 머리카락 가장자리 색·흐름 복원

마스크를 더 깎기보다 오염된 가장자리 픽셀을 깨끗한 머리카락·털의 색과 흐름으로 복원하고 실루엣과 정체성을 유지한다.

## 적용 조건

- 배경 교체 뒤 머리카락·털 가장자리에 원래 배경색이 남거나 곡선 방향이 깨진 경우에 적용한다.
- 마스크 윤곽은 맞지만 가장자리 픽셀의 색과 질감이 오염된 합성에 적용한다.

## 기술 절차

1. 먼저 문제가 마스크 누락인지 가장자리 픽셀의 색 오염인지 진단한다.
2. 색 오염이면 피사체 안쪽의 깨끗한 머리카락·털 질감을 기준으로 가장자리 색과 결을 복원한다.
3. 곡선 방향이 맞지 않으면 유사한 깨끗한 조각을 사용해 원래 흐름에 맞게 방향과 곡률을 조정한다.
4. 수정 결과가 실루엣 밖으로 새지 않도록 피사체 범위에 제한한다.
5. 서로 다른 밝기와 색의 임시 배경 및 전체 화면에서 잔색·반복 무늬·두꺼운 윤곽을 검사한다.

## 파라미터 가이드

- 브러시 크기·불투명도·Warp 수치는 원문에 없으므로 오염된 가장자리만 덮는 최소 범위로 결정한다.
- 깨끗한 안쪽 질감과 문제 부위의 방향이 유사한 소스를 선택한다.
- 곡률 보정은 원래 머리카락 흐름을 잇는 정도로만 제한한다.

## 판단 근거

- 같은 전문 기사에서 색 오염 복원과 곡선 흐름 재구성이라는 상보적 절차가 구체적으로 제시된다.
- 배경 교체의 대표적 실패를 막는 가치가 높고 Generate AI identity-preserve 정밀 편집으로 실행 가능하다.
- 독립 원문 근거가 아직 하나이므로 candidate로 발행한다.

## 주의사항

- 마스크를 계속 안쪽으로 깎으면 자연스러운 잔머리와 털이 사라진다.
- 한 지점의 질감을 반복 복제하면 패턴이 눈에 띈다.
- 곡선 흐름과 맞지 않는 직선 복원은 가발처럼 부자연스러워질 수 있다.
- 얼굴과 전체 헤어스타일 정체성을 바꾸지 않는다.

## 충돌 및 예외

- 실제 마스크 누락이 원인인 경우에는 픽셀 복원보다 먼저 선택 범위를 바로잡아야 한다.
