# 선형 카메라 프로파일에서 감마와 톤 응답을 직접 설계하는 RAW 그레이딩

기본 감마 곡선이 제거된 선형 카메라 프로파일에서 노출·색·톤을 조정한 뒤 사용자 곡선으로 최종 감마, 하이라이트 롤오프와 필름풍 대비를 설계한다.

## 적용 조건

- 고명암 RAW에서 기본 카메라 프로파일의 하이라이트 롤오프나 톤 응답이 창작 의도와 맞지 않을 때 적용한다.
- 부드러운 색 전이와 사용자 정의 필름풍 감마 곡선을 설계하려는 고급 RAW 그레이딩에 적용한다.

## 기술 절차

1. 카메라별 선형 프로파일을 준비하고 RAW에 적용한다.
2. 평평하고 어두워진 선형 시작 화면에서 노출과 기본 화이트 밸런스를 안정시킨다.
3. 색 분리와 필요한 국소·전역 보정을 선형 톤 응답 아래에서 진행한다.
4. 마지막에 사용자 Tone Curve로 중간톤 감마, 검정점, 흰점과 하이라이트 롤오프를 설계한다.
5. 기본 프로파일 결과와 비교해 클리핑, 색 전이, 피부색과 대비가 개선됐는지 검증한다.

## 파라미터 가이드

- 원문은 보편적인 곡선 좌표나 노출 수치를 제시하지 않으므로 만들지 않는다.
- 선형 프로파일 적용 직후의 어두움과 평탄함을 실패로 간주하지 말고 최종 감마 곡선 전 단계로 본다.
- Remaster와 LUT로 실행할 때는 실제 카메라 프로파일 생성 기능과 동일하다고 주장하지 말고 톤·색 응답의 근사 적용으로 한정한다.

## 판단 근거

- 서로 다른 날짜의 세 raw가 같은 원문에서 선형 프로파일, 선형 상태의 색보정, 최종 사용자 감마 곡선이라는 일관된 절차를 반복한다.
- 하이라이트 롤오프와 색 전이에 미치는 영향이 크고 고급 색보정에 재사용 가치가 있으므로 누락하지 않고 보존할 필요가 있다.
- 다만 모든 근거가 동일 PetaPixel 원문 계열이고 현재 지원 도구가 카메라 프로파일 생성을 직접 수행하지 못해 candidate가 적절하다.

## 주의사항

- 선형 프로파일은 카메라별 호환성이 필요하며 잘못된 프로파일을 적용하지 않는다.
- 최종 감마 곡선을 생략하면 평평하고 어두운 중간 결과가 남을 수 있다.
- 톤 곡선을 과도하게 만들어 하이라이트 클리핑, 검정 뭉침, 피부색 포화를 만들지 않는다.
- Remaster나 LUT 결과를 DNG Profile Editor 기반 선형 프로파일과 동일한 처리라고 오인하지 않는다.

## 충돌 및 예외

- 빠른 일반 보정이나 카메라 기본 렌더링이 이미 적합한 사진에는 추가 복잡성이 이득보다 클 수 있다.
- 기본 프로파일과의 비교에서 실질적인 색·톤 이득이 없으면 선형 워크플로를 강제하지 않는다.
